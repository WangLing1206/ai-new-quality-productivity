# 智启新质 — 人工智能赋能新质生产力

一个以数据可视化方式展现“人工智能作为新质生产力的作用和意义”的静态主题网站。

## 在线访问

https://wangling1206.github.io/ai-new-quality-productivity/

## 技术栈

- React 19 + TypeScript
- Vite 8
- Tailwind CSS
- ECharts 6
- Framer Motion
- Lucide React

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

项目通过 GitHub Actions 自动构建并部署到 GitHub Pages。

## 数据来源

- 中国信息通信研究院《人工智能发展白皮书（2024 年）》
- 国务院《新一代人工智能发展规划》
- PwC《Sizing the prize》
- Statista、工信部、国家统计局公开数据
